# Modül Dokümantasyonu (Modules)

Bu klasör, projedeki bileşenlerin teknik açıklamalarını barındırmak üzere ayrılmıştır.

## Mevcut Modüller
1. **Frontend Dashboard (`src/`)**: 
   - Vite ve TypeScript kullanılarak geliştirilmiş, Red vs. Blue Team simülasyonunu anlık yansıtan grafiksel kullanıcı arayüzü. Modül, saf CSS ile Glassmorphism estetiğine sahiptir.
2. **Saldırı ve Savunma Betikleri (`src/scripts/`)**:
   - Python kullanılarak yazılmış kurgusal PoC scriptleri. Recon (Keşif), Exploit (L2CAP Heap Overflow) ve IDS (Paket boyutu analizi) işlevlerini yerine getiren 3 farklı modülden oluşur.
