# Referanslar ve Kaynaklar (References)

Bu akademik araştırma ve PoC geliştirme sürecinde aşağıdaki kaynaklardan, araçlardan ve sunumlardan faydalanılmıştır:

## Akademik ve Sektörel Kaynaklar
1. **Pwn2Own Vancouver 2023:** Synacktiv Araştırma Ekibinin Tesla Model 3 üzerinde gerçekleştirdiği saldırının resmi konferans sonuçları.
2. **CVE Veritabanı:** 
   - [CVE-2023-32157](https://nvd.nist.gov/vuln/detail/CVE-2023-32157): Tesla Bluetooth Baseband Heap-based Buffer Overflow Zafiyet Bildirimi.
3. **Bluetooth L2CAP Spesifikasyonu:** 
   - Bluetooth Core Specification v5.x - L2CAP (Logical Link Control and Adaptation Protocol) mimarisi dokümantasyonu.
